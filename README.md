# Urban Temperature and Weather Pattern Analysis Across Indian Cities Using Data Analytics

## Project Overview
This project focuses on analysing historical temperature, rainfall and weather patterns across 10 major Indian cities using Data Science and Data Analytics techniques.

The project uses Python for data preprocessing and exploratory data analysis, along with Power BI for interactive data visualisation.

## Dataset Details
- Dataset: india_weather_cleaned.csv
- Total Records: 91,320
- Cities Covered: 10 Indian cities
- Time Period: 2000–2024
- Data Type: Historical daily weather observations

## Tools and Technologies
- Python
- Jupyter Notebook
- Pandas
- Matplotlib
- Power BI

## Project Methodology
1. Data importing
2. Data cleaning and preprocessing
3. Feature engineering
4. Exploratory Data Analysis (EDA)
5. Data visualisation
6. Interactive dashboard development

## Power BI Dashboards

### Dashboard 1: Temperature Analysis
Analyses maximum temperature variations across cities, months, years and seasons.

### Dashboard 2: Rainfall & Weather Patterns
Visualises monthly precipitation, city-wise precipitation, seasonal rainfall and weather condition distribution.

### Dashboard 3: City-wise Climate Comparison
Compares temperature range, apparent maximum temperature and wind speed across cities.

## Project Outcome
The project provides useful insights into historical weather variations, seasonal patterns and climatic differences across Indian cities through statistical analysis and interactive visualisations.

## Project Files
- `DataSci Project.ipynb` – Python analysis notebook
- `DataSci Project.html` – HTML version of the notebook
- `india_weather_cleaned.csv` – Cleaned dataset
- `ADS Final Project Dashboard.pbix` – Power BI dashboard file

## Conclusion
This project demonstrates how Data Analytics and interactive dashboards can be used to explore historical weather data and support better understanding of temperature and rainfall patterns across Indian cities.
